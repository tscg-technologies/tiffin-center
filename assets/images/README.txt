# TIFFIN CENTER - Image Assets Directory

This directory is reserved for image replacements generated via Google Flow or custom photography.

## Placeholder Replacement Instructions
1. Place food and venue images here (e.g. `dosa.jpg`, `idli-vada.jpg`, `meals-thali.jpg`, `hero-banner.jpg`, etc.).
2. In the HTML pages, replace the `<div class="image-placeholder ...">...</div>` containers with `<img>` tags referencing these assets, or keep the placeholder container and insert an `<img>` tag inside it.
3. Recommended image dimensions:
   - Hero banner: 1920x1080 (16:9)
   - Menu items / Food cards: 800x600 (4:3) or 600x600 (1:1)
   - Gallery images: 800x600 (4:3)
   - Feature / About images: 900x600 (3:2)

All current image visual elements are pure CSS-styled SVG/canvas-like placeholders adhering strictly to the demo requirements.
